## 1. 요청하신 수정 (반영 완료)

### 화면 표시
- 왼쪽 위에는 **진행 점(병원·입·식도·위·소장·대장)만** 시야 구석에 고정. 제목·할 일·상태 글자는 뺌
- 관람 화면 왼쪽 위 **"지금: 병원 진료실" 글씨 제거** (진행 점과 중복)
- **할 일 글 → 반짝이는 말풍선**: 관련 캐릭터 머리 위에 뜨고, 가리켜 누르거나 그 사람과 대화를 시작하면 닫힘. 진행 숫자(세균 4/6 등)도 말풍선에 같이 표시
- 체험관 시작 대기 화면에서는 말풍선 숨김

### 캐릭터
- **간호사가 땅만 보던 문제**: 누워 들어온 모형을 세우면서 몸 정면이 아래로 계산돼 있었음 → 얼굴·몸 정면을 따로 재서 바로 봄
- **살아 있는 동작**: 숨쉬기, 몸무게 옮기기, 가끔 두리번거리기, 말할 때 손짓 (애니메이션 파일이 아닌 코드로 뼈를 움직임)

### 병원
- **진찰 빨간 점**: 지름 12cm → 6cm, 맞힘 판정도 0.8m → 약 10cm (머리를 겨냥해도 대장이 맞던 문제 함께 해결)
- **화분 꽃 색**: 잎 재질이 텍스처 없는 흰색이었음 → 초록 잎
- **간호사 대화창**: 선택 버튼이 판 아래로 삐져나오던 것 → 대사 길이·버튼 수에 맞춰 판이 늘어남

### 입속
- 씹은 음식은 씹고 나면 사라지고, 삼킬 때 다시 나옴
- "혀" 같은 부위 이름표는 잠깐 깜빡이고 사라짐 (12초 안엔 다시 안 뜸)
- 혀 밑 침샘 구멍을 혀 아래(입바닥)로 옮김
- 침: 방울로 뚝뚝 떨어지던 것 → 혀 위를 흐르는 침 막 + 볼 안쪽 침 줄기 (씹는 동안 진해짐)

### 표적 힌트 (추가)
- 8초 동안 못 맞히면 남은 표적에 **노란 고리**가 숨 쉬듯 깜빡이고, 화면 밖이면 그쪽을 가리키는 **화살표**가 뜸 (세균·충치·헬리코박터균·유익균 등)
