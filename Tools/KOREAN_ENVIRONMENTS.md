# 한글 안내와 장면별 환경 배경

유니티 편집기 언어, 프로젝트에서 직접 만든 설정 항목·도움말·메뉴, 안내 문구와 자막을 한글로 정리했다. 현재 탐험 과정의 일곱 장면에는 장소에 맞는 배경을 만들고 연결했다. 기존 기관 모형, 위치, 충돌 영역과 진행 이벤트는 유지했다.

## 한글화

- 유니티에 설치된 한국어 언어 팩을 활성화하고 언어 선택을 저장했다. 별도 편집기 프로세스에서 한국어로 시작되는 것을 확인했다.
- 직접 만든 구성 요소 58종에 한글 메뉴와 설정창을 적용했다. 항목 이름 288개를 준비하고 실제 직렬화 필드와 중첩 자료의 표시 이름을 검사했다.
- 본문에 남아 있던 길이 단위, 산성도, 비타민 영문 표기 8곳을 한글로 바꿨다. 해당 안내 음성 6개도 기존 화자 설정으로 다시 생성했다.
- 이전 입 장면에 남아 있던 캐릭터 소개 문구 1곳도 한글로 바꿨다.
- 장기·장면·환경음 선택은 한글 목록으로 표시하며 내부 연결값은 유지한다. 새 연결값이 필요하면 설정창의 ‘직접 입력’을 사용한다.
- 코드 식별자, 파일명, 애니메이션 변수와 외부 플러그인의 고유 항목은 호환성을 위해 유지한다. 외부 플러그인 전체가 번역된 것은 아니다.

배경은 정적인 구면 무늬로 표현한다. 로비의 기존 천장 원판과 상영관의 불투명 외피는 표시를 꺼서 새 배경을 볼 수 있게 했다. 충돌 영역은 보존했다. 입과 위의 가까운 내부 벽에도 같은 무늬를 적용하여 화면을 가득 채우던 평평한 벽 색을 교체했다. 이전의 거대한 외곽 구체는 비활성화했다.

배경 재질은 `Assets/Data/Environments`에 한글 이름으로 저장했다. 색상·주름 깊이·표면 결·밝기를 조절할 수 있다. ‘인체탐험’ 메뉴에서 장면을 다시 생성해도 새 배경 연결이 유지되며, 만들어진 배경 재질의 수동 설정은 덮어쓰지 않는다.

## 검증

- [한글 및 환경 검사](korean_environment_validation.txt): 설정 항목, 도움말, 안내 문구, 글꼴 연결, 배경 셰이더와 장면 개체 수 검사에서 실패 없음.
- [언어 유지 검사](korean_editor_language_validation.txt): 새 편집기 프로세스의 저장된 언어와 실제 시작 언어 모두 한국어.
- [탐험 진행 검사](korean_environment_journey.txt): 로비 → 입 → 식도 → 위 → 소장 → 대장 → 상영관 → 로비 순환에서 29개 검사 통과.
- 장면별 배경 단독·정면·좌우·뒤·천장·전체 배치, 총 49장 촬영. 배경 7종과 배경을 가리던 외피 수정 결과를 이미지로 확인했다.
- 현재 안내 대본과 탐험 장면 자료에서 영문 설명이 검출되지 않았다. 코드 연결용 문자열과 서식 표시는 설명 검사 대상에서 구분했다.

진행 검사는 대기 시간을 단축하고 상호작용을 자동 호출했다. 실제 헤드셋의 양안 표시, 손·컨트롤러 입력, 음성 청취 품질과 실기 성능을 검증한 결과는 아니다. 기존 장치 실행 문제와 점검 범위는 [이전 검증 기록](VALIDATION.md)에 기록되어 있다.

## 보관 및 다시 적용

이번 적용 전 파일은 작업 폴더의 `korean-environments/original`에 별도로 보관했다. 편집기 언어의 기존 선택은 `Tools/editor_language_before.json`에 보관했다. 기존 미커밋 작업과 앞서 수정한 진행 오류 해결 내용을 유지했으며 별도 커밋은 만들지 않았다.

메뉴 ‘인체탐험 → 4. 한글 안내와 환경 배경 적용’으로 기존 장면에 배경과 안내를 다시 적용할 수 있다. 실행하면 장면 자료와 촬영본을 저장하므로 수동으로 작업 중인 장면은 먼저 저장한다.

검증에 사용한 유니티 버전은 `6000.2.1f1`이다.
