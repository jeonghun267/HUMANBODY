# 탐험 환경과 소화 연출 보완

2026년 9월 22일. 별도 사본에서 검증한 뒤, 편집기가 닫힌 원본을 백업하고 보완을 반영했다. 원본에서도 보완 동작 36개와 전체 탐험 왕복 30개 검사를 다시 통과했다. [수정 화면](POLISH_REVIEW.md)을 함께 확인할 수 있다.

## 환경

- 기관 배경에서 회오리·방사형 주름·시간에 따른 무늬 변화를 제거했다. 단계별 차분한 색상만 남겼다.
- 위턱의 불필요한 앞뒤 회전을 제거해 위아래 앞니 방향을 맞췄다. 치관은 서로 마주보고, 두 치열 사이에는 관찰 공간을 확보했다.
- 혀를 낮춰 탐험자 눈높이를 가리지 않게 했다. 구강 벽과 천장의 범위도 치열에 맞췄다.
- 식도·소장·대장은 실제 이동 경로를 둘러싸는 연속 벽으로 교체했다. 기존의 엇갈린 관 조각은 비활성화하고 원본 모형 자료는 보존했다.
- 통로 단면 방향을 고정해 꼬임을 방지했고 끝부분도 벽으로 마무리했다. 이동 경로 아홉 지점에서 사방 벽의 충돌과 여유 공간을 검사한다.
- 통로로 튀어나오던 캡슐 외피를 숨기고 발판과 난간을 남겼다. 이동·정차·안내 연결은 유지한다.
- 위와 대장의 공중 패널을 숨기고 주름을 벽 모형에 통합했다. 화면을 덮는 큰 점액 구체는 숨겼다.
- 괄약근 중앙의 고정 덩어리를 제거했다. 이제 문이 열리면 중앙 구멍 자체가 넓어지고 통과 차단도 해제된다.

## 침과 소화 효과

침샘 여섯 개를 씹기 연출 하나에서 시작하고 종료한다. 정상 종료에는 새 분비를 멈추고 남은 입자가 자연스럽게 사라진다. 중단에는 침과 접촉 물방울, 씹는 소리를 정리하고 턱·음식 자세를 복원한다. 중복 시작이나 중단 후 재시작도 검사했다.

침·위산·분비액에는 둥근 물방울 재질과 표면 접촉 입자를 연결했다. 접촉 입자는 한 화면 갱신당 방출량을 제한한다. 위의 음식은 표면부터 점차 분해되며 미즙으로 전환된다. 취소 시 표면과 크기를 복원한다. 단백질 절단 순간에는 작은 조각 효과를 방출한다. 기존 영양소 흡수 빛과 수분 흡수 파문도 유지한다.

## 캐릭터 동작

기존 일곱 모형의 외형과 표면 그림을 유지하며 관절이 있는 모형을 생성했다. 모형 이동과 관절 동작을 나누어 기존 따라오기·군집 이동·혈관 경로와 충돌하지 않게 했다.

- 안내 병아리: 머리·부리·팔·날개 동작, 처음 등장할 때 인사, 설명 대상 쪽으로 고개 돌리기. 음성이나 안내가 끝나거나 건너뛰면 말하기 동작도 종료한다.
- 펩신: 단백질 절단 시 팔을 모으고 기본 동작으로 복귀한다.
- 소화 효소·유익균·유해균: 서로 다른 속도의 몸통·팔·하체 동작을 갖는다.
- 바이러스·적혈구: 형태 일부가 부드럽게 변하며 기존 경로로 이동한다.

안내 부리 동작은 음성 세기와 안내 상태에 따른 연출이다. 발음별 입 모양을 맞추는 방식은 아니다. 미생물의 동작도 교육용 캐릭터 표현이다.

## 검증

보완 동작 36개, 기존 효과 34개, 이동·안내 회귀 15개, 전체 탐험 왕복 30개 검사를 통과했다. 별도로 다섯 셰이더 컴파일, 일곱 캐릭터의 관절 가중치와 내부 변형, 통로 벽 연결을 검사한다. 안내자의 부리에는 실제로 영향을 받는 모형 점 120개가 연결된다.

검사는 컴퓨터의 유니티 재생과 자동 촬영 기준이다. 실제 헤드셋의 양안 표시·손 입력·체감 멀미·기기 성능·음성 청취는 별도 확인이 필요하다. 화면 전환의 시각적 완료도 헤드셋 또는 게임 화면에서 확인해야 한다.

## 유지보수

`JourneyPolishSetup.Apply`가 관절 원본과 실제 장면 연결을 생성한다. 장면을 다시 만드는 경우에도 `JourneyBuilder`에서 같은 환경·효과 설정을 적용한다. 새 설정 항목과 메뉴는 한글로 표시한다. 기존 탐험자 시점과 안내 대사는 유지한다.

자료 위치는 `Assets/Data/Generated/Characters`, `Assets/Data/Generated/Effects`, `Assets/Data/Generated/EnvironmentRepair`이다. 기존 모형 원본은 덮어쓰지 않는다. 자동 촬영은 `Tools/polish_captures`, 검사 결과는 `Tools/polish_*.txt`에 저장한다.
