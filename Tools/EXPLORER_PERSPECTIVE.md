# 작은 탐험가의 몸속 여행

플레이어는 **병아리 의사 삐약이와 함께 음식의 이동 경로를 따라가는 작은 탐험가**다. 입구를 지나 몸속에 들어가며, 음식이 소화되고 영양소가 흡수되는 과정을 가까이에서 관찰한다. 안내 캐릭터는 탐험의 동행자이고, 음식·영양소·물방울은 관찰 대상이다.

## 장소별 경험

| 장소 | 탐험가의 경험 |
|---|---|
| 로비 | 안내 캐릭터를 만나 탐험가의 역할과 몸속으로 들어가는 설정을 듣는다. |
| 입 | 주변을 둘러보며 이가 음식을 씹고 혀가 식괴를 보내는 과정을 관찰한다. 이동 안내를 들은 뒤 화면 전환으로 식도에 간다. |
| 식도 | 탐험 캡슐을 타고 음식의 이동과 연동 운동을 관찰한다. |
| 위 | 걸으며 위산, 위벽 수축, 음식의 미즙 변화를 관찰한다. 미즙의 이동 경로를 따라 소장으로 간다. |
| 소장 | 캡슐을 타며 영양소를 바라봐 흡수 과정을 관찰한다. 진행 문구는 ‘흡수 관찰’로 표시한다. |
| 대장 | 캡슐에서 물방울의 흡수와 찌꺼기의 변화를 관찰한다. 관찰을 마치면 정리 상영관으로 이동한다. |
| 정리 상영관 | 탐험 중 관찰한 음식의 여정을 되짚는다. |

## 반영 사항

- 도입·이동·체험·마무리 대사 19개를 탐험가 시점으로 수정했다.
- 같은 19개 음성을 기존 한국어 안내 화자의 설정으로 다시 생성하고, 자막과 실제 장면 연결을 확인했다.
- 입에서 플레이어까지 목구멍으로 끌어당기던 설정을 껐다. 음식 자체의 씹기·삼킴 연출을 관찰하고, 안내가 끝나면 화면 전환으로 다음 장소에 이동한다.
- 자동 탑승은 최소 대기 시간과 입장 안내가 모두 끝난 뒤 시작한다. 긴 도입 대사가 캡슐 정차 안내에 끊기는 일을 방지한다.
- 원본 대본, 장면 생성 코드, 음성 생성 대사, 저장된 일곱 장면, 편집기 항목과 프로젝트 설명에 같은 설정을 적용했다.

새 음원 19개의 파일이 생성 기록과 일치함을 확인했다. 유니티가 음원을 읽고 새 자막에 연결하는 것까지 검사했으며, 실제 장치의 청취 품질과 화면 전환은 별도 확인 대상이다. 진행 검사는 대기 시간과 이동 시간을 줄여 실행했다.

자동 적용의 한 실행은 저장을 마친 뒤 유니티 종료 대기에서 시간 제한에 걸렸다. 이후 새 유니티 프로세스에서 저장된 자료를 다시 열어 위 검사를 모두 통과했다.
